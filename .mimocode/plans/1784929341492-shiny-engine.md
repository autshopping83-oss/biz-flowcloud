## Problemas encontrados 🔴

### 1. `robots.txt` com typo (já corrigido localmente, NÃO commitado)
**Ficheiro:** `public/robots.txt:4`
- `Sitemap: https://biz-flo.cloud/sitemap.xml` → devia ser `biz-flow.cloud`

### 2. Sitemap desatualizado (já corrigido localmente, NÃO commitado)
**Ficheiro:** `public/sitemap.xml`
- Faltava `/testar` (página DemoEditor)
- Todas as datas eram `2026-04-27` → atualizadas para `2026-07-28`

### 3. `og:image:width` e `og:image:height` em falta
**Ficheiros:** `index.html` + `src/components/Seo.tsx`
- Estas meta tags ajudam crawlers a determinar dimensões da imagem antes de a carregar
- Evitam layouts quebrados em rich snippets e WhatsApp/LinkedIn previews

### 4. `og:image` é SVG (pode não renderizar em algumas plataformas)
**Ficheiro:** `index.html:29`, `Seo.tsx:6`
- WhatsApp, LinkedIn e alguns crawlers não renderizam SVG como `og:image`
- Existe `logo.png` em `public/` que devia ser usado como fallback ou primário
- **Solução:** usar `logo.svg` para favicon, mas `logo.png` (512x512) para `og:image`

### 5. P-gina- é uma SPA — sem SSR/SSG
- Ao contrário do blog (Next.js com SSG), o site usa Vite + react-router-dom (client-side)
- Google renderiza JS, mas meta tags dinâmicas (react-helmet-async) dependem de JS
- Crawlers mais simples podem ver apenas o `index.html` default
