# Plano: Workflow CI/CD para Huawei AppGallery (AAB)

## 1. Resumo

Criar um novo workflow GitHub Actions (`build-huawei-aab.yml`) para compilar o AAB do
app Capacitor direcionado à Huawei AppGallery com HMS Core. O workflow existente
(`build-aab.yml` — Google Play) permanece intocado.

## 2. Arquivos envolvidos

| Arquivo | Ação |
|---|---|
| `.github/workflows/build-huawei-aab.yml` | **CRIAR** — novo workflow Huawei |
| `android/build.gradle` | ✅ **JÁ OK** (repositório Huawei + classpath AGConnect) |
| `android/app/build.gradle` | ✅ **JÁ OK** (plugin AGConnect + HMS Push Kit) |
| `android/app/agconnect-services.json` | ✅ **JÁ OK** localmente (gitignored) |

## 3. O Gradle command

**`./gradlew bundleRelease --no-daemon`** — exatamente o mesmo comando do workflow
Google Play. O plugin `com.huawei.agconnect` processa `agconnect-services.json`
automaticamente durante o build. Nenhuma flag extra é necessária.

A saída será em `android/app/build/outputs/bundle/release/app-release.aab`.

## 4. Novo workflow: `.github/workflows/build-huawei-aab.yml`

```yaml
name: Build Huawei AppGallery AAB

on:
  push:
    branches: [main]
  workflow_dispatch:

concurrency:
  group: build-huawei-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install dependencies
        run: npm install

      - name: Build web app
        run: npm run build

      - name: Sync Capacitor
        run: npx cap sync

      - name: Setup Java 17
        uses: actions/setup-java@v4
        with:
          distribution: 'zulu'
          java-version: '17'

      - name: Setup Android SDK
        uses: android-actions/setup-android@v3

      - name: Decode keystore from secret
        run: |
          echo "${{ secrets.KEYSTORE_BASE64 }}" | base64 -d > android/app/bizflow-android.keystore

      - name: Decode agconnect-services.json from secret
        run: |
          echo "${{ secrets.AGCONNECT_SERVICES_JSON }}" | base64 -d > android/app/agconnect-services.json

      - name: Build AAB Release (assinado + HMS)
        run: |
          cd android
          ./gradlew bundleRelease --no-daemon

      - name: Upload AAB (Huawei)
        uses: actions/upload-artifact@v4
        with:
          name: app-huawei-release-aab
          path: android/app/build/outputs/bundle/release/app-release.aab
          retention-days: 30
```

**Diferenças para o workflow Google Play:**
- `name:` diferente → `Build Huawei AppGallery AAB`
- `concurrency.group:` prefixo `build-huawei-` para não conflitar
- **Step novo**: decodifica `AGCONNECT_SERVICES_JSON` → `android/app/agconnect-services.json`
- `upload-artifact` com `name: app-huawei-release-aab`

## 5. GitHub Secrets necessários

| Secret | Descrição | Já existe? |
|---|---|---|
| `KEYSTORE_BASE64` | Keystore `.jks` em base64 (mesmo usado no Google Play) | ✅ Sim |
| `AGCONNECT_SERVICES_JSON` | `agconnect-services.json` em base64 (**NOVO**) | ❌ Criar |

### Como gerar o `AGCONNECT_SERVICES_JSON`

```bash
# No diretório do projeto local:
base64 -w0 android/app/agconnect-services.json
# Copie a saída e crie o secret no GitHub:
# Settings → Secrets and variables → Actions → New repository secret
# Name: AGCONNECT_SERVICES_JSON
# Value: <cole a string base64>
```

## 6. Dependências HMS Core incluídas

Atualmente apenas **HMS Push Kit** (`com.huawei.hms:push:6.11.0.300`).
Se no futuro o app usar Mapas, Login, Pagamentos etc., adicionar no
`dependencies` do `android/app/build.gradle`.

## 7. Verificação

1. **Fazer o push do novo workflow** para o repositório Huawei
2. **Configurar o secret** `AGCONNECT_SERVICES_JSON` no GitHub (Settings → Secrets)
3. **Acionar manualmente** o workflow via `workflow_dispatch` (GitHub Actions tab)
4. **Verificar o log**: o build deve mostrar `AGConnect` sendo processado nas tasks
5. **Baixar o artifact** `app-huawei-release-aab` e verificar:
   - É um `.aab` válido
   - Assinado (verificar com `jarsigner -verify`)
6. **Fazer upload** na AppGallery Connect → deve aceitar sem erros de configuração

## 8. Observações

- O `agconnect-services.json` NÃO deve estar versionado no git (já está no `.gitignore`)
- O Google Play workflow original permanece intacto em `build-aab.yml`
- O mesmo keystore pode ser usado tanto para Google Play quanto Huawei AppGallery
